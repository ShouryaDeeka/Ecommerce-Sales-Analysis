# RetailPulse — Ecommerce Sales Dashboard

A complete Excel-based business intelligence dashboard designed to transform raw ecommerce transactions into meaningful business insights using interactive visualizations and dynamic reporting.

Built entirely using native Excel features without external tools or add-ins.

---

## Project Overview

This project focuses on analyzing ecommerce sales performance across different regions, categories, and time periods through an interactive dashboard interface.

The dashboard enables users to:

- Monitor overall sales performance
- Compare regional revenue contribution
- Track category-wise growth
- Identify high-performing products
- Analyze monthly sales trends
- Filter insights dynamically using slicers

## How to Use

1. Download the Excel workbook
2. Open using Microsoft Excel (2016 or later recommended)
3. Navigate to the **Dashboard** sheet
4. Use slicers to interact with the report dynamically
